**A collection of reusable UI components, animations, and interactive experiments.**

Built with React, TypeScript, and modern front-end technologies.

## Introduction

A growing collection of reusable components created to explore different approaches to interface design, animation, and front-end development.

This repository brings together interactive elements, motion experiments, and UI patterns that can be adapted and integrated into other projects.

The focus is on building components that are visually refined, flexible, and maintainable.

## Technologies

| Technology | Purpose |
| :--- | :--- |
| **React 19** | Component development |
| **Next.js 16** | Development environment |
| **TypeScript** | Type safety |
| **Tailwind CSS 4** | Styling and responsive design |
| **Motion** | Animations and transitions |
| **Lenis** | Smooth scrolling |
| **OGL** | WebGL and visual effects |

## Components

The collection explores several areas of interface development.

**01. UI Components**

Reusable interface elements designed with consistency, accessibility, and flexibility in mind.

**02. Motion & Interactions**

Animated components, transitions, and interaction patterns that enhance user experiences.

**03. Visual Experiments**

Creative implementations involving typography, layouts, WebGL, and interactive effects.

**04. Responsive Design**

Components designed to adapt across different devices, screen sizes, and layouts.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/eryckassis/about-me.git
```

Navigate to the project directory:

```bash
cd about-me
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to explore the components.

## Using the Components

Components are intended to be adapted and reused across different React projects.

To use an individual component:

1. Locate the component in `app/components/`.
2. Copy the component and its required assets.
3. Install any necessary dependencies.
4. Import it into your application.
5. Customise its styling, behaviour, and content.

Some components may rely on project-specific styles, animations, or supporting utilities.

Review their dependencies before integrating them into another project.

## Development Principles

**Reusability**

Components should be easy to adapt without unnecessary duplication.

**Maintainability**

Readable code, consistent patterns, and clear separation of responsibilities.

**Performance**

Thoughtful animations, efficient rendering, and minimal unnecessary complexity.

**Interaction**

Motion and interactive behaviour should serve a purpose and contribute to usability.

**Visual Quality**

Careful attention to typography, spacing, responsiveness, and details.
